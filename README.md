* 🥁 **[Drum Sheet Sync](https://github.com/UnkGuy/drum-sheet-sync)** — Full-stack AI sight-reading web app combining a fine-tuned **YOLOv8 / ONNX** measure detection pipeline (`1024x1024` rasters), 1D reading-order row clustering in **FastAPI**, and a 60fps **Next.js + Web Audio API** player.
* 🗺️ **[SiteSuri](https://github.com/averageCoder-bit/sitesuri)** — Geospatial decision-support platform for Filipino MSMEs built with **Next.js, MapLibre GL, FastAPI, and Supabase**, powered by an **XGBoost Poisson** pedestrian-activity model and multi-factor suitability scoring.
* 📜 **[Viggy's Archive (`devcomm-blog`)](https://github.com/UnkGuy/devcomm-blog)** — Full-stack TTRPG blogging platform built on **Next.js 15 (App Router)** and **Supabase**, featuring PostgreSQL Row-Level Security (RLS), IDOR protection, XSS sanitization, and `Promise.all()` SSR optimization.
* 🏢 **[ShopZada 2.0 / ZadaLytics](https://github.com/averageCoder-byte/ZadaLytics)** — Containerized Kimball enterprise data warehouse (**PostgreSQL, Docker Compose, Airflow/Kestra**) modeling 2M+ order line items with SCD Type 2 dimensions, monthly table partitioning, and PII data masking.
* 🌫️ **[PH Urban AQI Classification ML](https://github.com/averageCoder-byte/ph-aqi-classification-ml)** — Multiclass air quality benchmark across Philippine cities comparing **LightGBM (0.9704 Macro F1 / 99.69% Accuracy)**, **CatBoost**, **Balanced MLP-NN**, and **RBF-Kernel SVM**.
* 🎲 **[Pocket Crawler](https://github.com/UnkGuy/PocketCrawler) & [KLScents E-Commerce](https://github.com/UnkGuy/Perfume)** — Modular D&D 5e roguelite engine in **Dart/Flutter** and a production fragrance storefront deployed on **[Vercel](https://perfume-gilt-iota.vercel.app/)**.
